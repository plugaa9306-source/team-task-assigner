# מחולל שיבוצי משימות

Vanilla JS (ES Modules) + Web Components. ללא Build, ללא תלויות.

## הרצה
ES Modules ו-fetch לא עובדים מ-file://, לכן יש להריץ שרת סטטי:

    python3 -m http.server 8000

ואז לפתוח http://localhost:8000

## עריכת נתונים
כל הנתונים בתיקיית `data/` (אנשים, משימות, תפקידים, תבנית ההודעה).
